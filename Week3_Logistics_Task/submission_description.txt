This Week 3 project presents an end-to-end exploratory data analysis and visualization workflow for a hypothetical logistics operation using Python. A reproducible simulated dataset of 300 logistics orders was created with variables covering carrier, route region, distance, shipment volume, warehouse delay, fuel price index, delivery time, transport cost, and delivery status. The analysis begins with data inspection and quality checks, followed by missing-value treatment using median imputation and IQR-based outlier handling. Descriptive statistics were then calculated to understand central tendency and variability. Correlation analysis was used to examine relationships among distance, shipment volume, warehouse delay, delivery time, and transportation cost.

Multiple visualizations were created using Matplotlib, including a delivery-time histogram, route-level shipment-volume comparison, distance-versus-cost scatter plot, warehouse-delay-versus-delivery-time scatter plot, correlation matrix, and carrier cost comparison. These visualizations make it easier to identify operational patterns and potential cost drivers. In the simulated data, distance shows a positive association with transport cost, while warehouse delay is associated with delivery time. The analysis also highlights the route with the highest average shipment volume and compares average simulated transportation cost across carriers.

The accompanying DOCX report documents the methodology, analytical reasoning, visualizations, interpretations, Python code excerpts, recommendations, and limitations. The complete Python script and both raw and cleaned datasets are included in the GitHub project for reproducibility. Because the dataset is hypothetical, the findings are intended to demonstrate analytical technique rather than represent actual company performance.
