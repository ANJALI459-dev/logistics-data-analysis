# Week 3 – Advanced Data Analysis and Visualization in Logistics

## Objective
This project performs exploratory data analysis (EDA) and visualization on a hypothetical logistics dataset using Python.

## Dataset
The dataset contains 300 simulated logistics orders and variables covering:
- delivery time
- shipment volume
- transportation cost
- distance
- warehouse delay
- fuel price index
- carrier
- route region
- delivery status

## Analysis performed
1. Dataset inspection and descriptive statistics
2. Missing-value handling using median imputation
3. IQR-based outlier treatment
4. Central tendency and distribution analysis
5. Correlation analysis
6. Multiple logistics visualizations
7. Operational interpretation and recommendations

## Main findings from this simulated dataset
- Average delivery time: 3.93 days
- Median delivery time: 3.88 days
- Average transport cost: ₹4,495
- Late-delivery share: 9.0%
- Distance vs cost correlation: 0.76
- Warehouse delay vs delivery time correlation: 0.58
- Shipment volume vs transport cost correlation: 0.20

**Note:** This is a hypothetical/simulated dataset created for the internship task and is not a record of real company operations.
